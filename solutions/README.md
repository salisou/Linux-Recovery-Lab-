# Soluzioni – uso docente

Le soluzioni complete vanno mantenute separate dalle consegne degli studenti.

Criteri generali di correzione:
- comando appropriato e sintassi corretta;
- spiegazione di scopo, opzioni e argomenti;
- distinzione tra sola lettura e modifica;
- interpretazione dell'output senza conclusioni non supportate;
- precauzioni e piano di rollback;
- documentazione chiara e riproducibile.

Per esercizi su log, la soluzione dipende dai dati del file di laboratorio distribuito dal docente. Non assumere un output identico su tutte le macchine.
