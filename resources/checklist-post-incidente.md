# Checklist post-incidente

## Prima del ripristino
- [ ] Sistema identificato (Kali/Ubuntu, versione, VM).
- [ ] Ambito e sintomi descritti.
- [ ] Log e informazioni diagnostiche raccolti.
- [ ] Snapshot e backup individuati.
- [ ] Piano di rollback definito.

## Dopo il ripristino
- [ ] Avvio completato.
- [ ] Filesystem e mount point verificati.
- [ ] Spazio disco controllato.
- [ ] Servizi necessari verificati.
- [ ] Log controllati per nuovi errori.
- [ ] Integrità dei file recuperati verificata.
- [ ] Connettività di laboratorio verificata.
- [ ] Risultati e tempi documentati.
- [ ] Causa probabile e azioni preventive registrate.

**Esito:** ☐ Ripristino riuscito ☐ Parziale ☐ Non riuscito

**Note:** descrivere evidenze osservate, non supposizioni.
